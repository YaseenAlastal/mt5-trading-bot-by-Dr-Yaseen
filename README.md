# MT5 Dual-Strategy Elite Trading Bot

نظام تداول آلي ذكي ومتطور لمنصة MetaTrader 5، يدعم حسابات السنت والدولار، ويتضمن نمطين رئيسيين:
1. **Grid & Martingale Strategy:** استراتيجية التداول المتكرر والمضاعفات لحسابات السنت مع هدف ربح كلي 50 سنت.
2. **AI SMC Institutional Strategy:** المساعد الذكي، تحليل الأموال الذكية (SMC)، وتقارير الأداء اليومية.
